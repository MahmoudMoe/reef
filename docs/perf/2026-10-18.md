## Method

Every number comes from the session transcripts under `~/.claude/projects/<trial>/`, read after the fact, never from
an agent's own report:

- **main-session turns** = distinct API responses of the orchestrator (one `message.id` each; the transcript splits a
  response into several entries, so a raw line count over-counts about 2×);
- **growth** = `scripts/reef-cost.py growth <task>`: the sum of the positive context deltas over the task's span in the
  main session, across sessions (`.reef/cost/tasks.json`, written by the Stop hook). It over-counts when two tasks are
  active in the same turns — 202 and 203 ran side by side, so both carry the shared turns;
- **agent turns / max ctx / cache reads** = the same count over each sub-agent's transcript
  (`<session>/subagents/agent-*.jsonl`, `…/workflows/<wf>/agent-*.jsonl` for a workflow agent); cache reads are the sum
  of `cache_read_input_tokens`, the figure that dominates the bill;
- the handoff table's `growth` values were taken live by the orchestrator; where they differ from `tasks.json` the
  record is the one here, with the orchestrator's figure beside it.

## C. Task 1102 in graph mode (0.7 defaults) — in flight

`run-5f75354487.js` generated 10:24Z with `"hunter": false` (guard pass per feature) for one task, 21 criteria,

The implementer's cost is the task's, not the mode's: a 21-criterion auth task with a migration and three new packages
costs 50–70 implementer turns either way. The only line graph mode is designed to move is the orchestrator's: ~25
turns at 90–150k context per task in chat mode against one call and one read. The implementer was denied once by the
guard (a vitest run piped into another command, by design) and hit 175k of context — above the orchestrator's ceiling,
which does not apply to an agent; it auto-compacts.

To fill at settle: `python3 scripts/reef-cost.py growth 1102` (role `workflow`), the verifier's turns and context, wall
time to `READY TO MERGE`, and whether `settle` was clean. The decision rule from `workflow-v2.md` phase 3: graph mode
becomes the loop's default for `dispatch now` only on the numbers.
