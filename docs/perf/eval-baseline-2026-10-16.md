# Judging-agent eval baseline — 2026-10-16

Item 0.4 (decision 4: measure before optimising). `scripts/reef-eval run <agent> --k 3` on the frozen corpus
`tests/eval/corpus/{verifier,hunter,plan-reviewer}.json`: every run is `claude -p` headless with this plugin loaded
and the agent file appended as system prompt, in a fresh worktree built from the entry's files, judged mechanically
by `reef-eval score` (VERDICT line, BLOCKER / BLOCKING / `AC<n> FAIL` lines against the entry's truth regexes).
Models: the agent files' defaults — verifier opus, loophole-hunter opus, plan-reviewer fable.

Reports: `.reef/eval/<agent>/<entry>-<k>.txt` (machine state, not committed); the scored JSON per agent is
`.reef/eval/<agent>-baseline.json`. Per-run cost: $0.21–0.59 opus, $0.53–1.18 fable.

### What the baseline taught (before any agent text changed)
- **The corpus's PASS entries were wrong twice, and the agents were right.** The first "correct" summarize fixture
  accepted `nan` as a number and pinned the warning index only at row 0; the first "sound" commit guard let
  `git -C dir commit -n`, `--no-veri`, `-nm"fix 1"` and a heredoc through, then (round 2) read a glued `-m` value as
  flags and denied legitimate commits, then (round 3) split a segment on `2>&1` and ate the rest of a heredoc's
  line; its Log claimed "15 of 17 red" when the measured count was 14 of 18. Each round the hunter cited file:line
  and ran the probe. The fixtures were hardened and the Log is now **generated by running the previous guard** — a
  prose claim the code contradicts is exactly the defect class the eval exists to catch, and it caught the author.
- **Precision, not recall, is the weakness.** Every true blocker was caught in every run. The misses are false
  FAILs: a verifier failing a correct diff because "the test could be stronger" (zeroing a bad amount would pass
  it) or because `nan` was not in the task; a hunter raising a `#`-in-a-word shlex quirk the task's Scope had
  declared out of scope. This is the cost 2.3 (the four-kind blocking bar) exists to remove.
- **Report shapes vary**: findings arrive as `AC3: FAIL`, `AC-3 — FAIL`, `| AC3 | **FAIL** |`, `**BLOCKING**`
  sections and quoted `` `VERDICT: PASS` ``. The parser accepts all of these now (fixture replay in
  `tests/test_eval.py`); a verdict the parser cannot read counts as unparsed, never as a catch.
